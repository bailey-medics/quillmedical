# Pull request description log

One entry for every pull request description written by `/crpd`, newest
first. The entry records the readability scores the description reached
and, beside them, what the reader made of it. The scores are information
and never a gate: the verdict is the test, and the rules in
`.claude/skills/crpd/SKILL.md` move when the verdicts say they should.

Each entry has four lines:

- **Scores** - the Flesch reading ease of every attempt, in order, then
  which attempt was posted. `/crpd` writes this line.
- **Rules** - the pull request that last changed the skill file the
  description was written to. `/crpd` writes this line.
- **Verdict** - the reader's own words, added when they give it in chat or
  in a review.
- **Changed** - the rule that moved because of that verdict, linking the
  pull request that moved it.

The plan behind this file is
[readable pull request descriptions](../plans/2026-10-31-readable-pull-request-descriptions-plan.md).
