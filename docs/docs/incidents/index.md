# Incidents

A record of each time Quill stopped working as it should, what caused it,
and what was done about it. Each report ends in actions, so the way outages
are prevented, noticed and handled improves with each one.

Every report has the same headings, one file per incident, newest first in
the list below.

- [2026-10-20: Google Cloud power outage in europe-west2](2026-10-20-europe-west2-power-outage.md) -
  six hours without database connections from Cloud Run; nothing lost
- [2026-10-19: GitHub Actions degraded](2026-10-19-github-actions-degraded.md) -
  a deploy that had worked showed as stuck for half an hour; nothing lost
